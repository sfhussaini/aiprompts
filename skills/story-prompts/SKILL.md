# 🎬 Story Decomposition Template

This skill is used to decompose a narrative from the highest level (Movie) down to the atomic visual unit (Frame). It organizes the story into a logical progression and integrates specific image prompt generation for every frame.

## Structure Flow Reference
**Movie** => **Scene** => **Segment** => **Clip** => **Frames**

---

## 🛠️ Integration Logic: Frame Generation
For every entry in the `frames` list, you must apply the logic from the **`prompt-formula`** skill. 

*PREPROCESSING STEP: Before applying @prompt-formula, review the extracted narrative description. If the action relies on a subject established in the previous sentence (e.g., 'She lifts her saree'), rewrite that clause to be fully self-contained and explicit (e.g., 'Lifting her saree...'). Ensure every descriptive phrase clearly states *who* is performing the action.*

Each "Frame" is not just a title; it is a collection of visual data. When processing a Frame, you must generate:
1. A descriptive **title**.
2. A JSON object containing `postive_prompt`, `negative_prompt`, and `wh_ratio` (generated using the rules in `@prompt-formula`).

---

## 🎥 Template Instance: Story Decomposition Block

**Movie**
[movie description] - *The overarching narrative context for this entire sequence.*

**Scene**
[Scene description] - *A major visual or narrative break within the movie (e.g., "The Chase," "The Confrontation").*

**Segment**
[Segment description] - *A sub-division of a scene, often based on a specific action, topic, or mood shift.*

**Clip**
[Clip description] - *A short, continuous sequence of footage captured from the original recording. This is the primary unit for editing.*

**Frame**
Frame X: [Frames description] - *The individual moment/snapshot within the Clip. '120' should be replaced with the specific frame number.*
